# Tech Stack

## Backend:
- PHP: Phiên bản 8.2 trở lên.
- Laravel Framework: Phiên bản 12.x.

## Database:
- MariaDB: Phiên bản 10.5 trở lên.

## Frontend:
- Node.js: Phiên bản 18.x trở lên.
- Tailwind CSS: Phiên bản 4.0.0.
- Vite: Phiên bản 6.2.4.

## Công cụ và thư viện hỗ trợ:
- Composer: Quản lý các gói PHP.
- npm: Quản lý các gói JavaScript.
- Laravel Vite Plugin: Tích hợp Vite với Laravel.
- Concurrently: Chạy nhiều lệnh đồng thời.
- Axios: Thư viện HTTP client.

## Testing:
- PestPHP: Framework testing cho PHP.
- Mockery: Thư viện mock cho PHP.

## DevOps:
- Laravel Sail: Môi trường phát triển dựa trên Docker.
